# Smooth Gravatar

A React + Vite identicon generator that creates mirrored 5x5 avatars with curated color palettes and rounded cell geometry.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

This project is configured for Pages deployment using the `gh-pages` branch.

```bash
npm run deploy
```

After first deploy, enable Pages in your repository settings and set the source to:
- Branch: `gh-pages`
- Folder: `/ (root)`
